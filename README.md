# S1000D Mini-CSDB v1.1

A browser-based educational CSDB emulator built around the S1000D Issue 6 R2 Bike sample data.

## What it demonstrates

- Browse real S1000D Bike Data Modules and other objects
- Search by DMC, title, filename and schema
- Inspect metadata, readable content and source XML
- Follow `dmRef` links and Publication Module references
- Preview browser-compatible ICN illustrations referenced by a module
- See referenced ICNs that require formats such as CGM even when no browser preview is available
- Run a small set of **BREX-informed checks** read from the actual Bike BREX Data Module
- Simulate Check out → In Work → Review → Approval → Issued
- Keep an audit trail in browser `localStorage`
- Import another extracted S1000D XML folder locally

## Important scope note

This is an educational emulator, not a production CSDB, a full BREX engine, or an S1000D conformance validator. Workflow edits are local simulations and do not modify source XML.

## Run

Open `index.html` in a modern browser. No server or build process is required.


## v1.1 authoring workflow
A checked-out Data Module is now opened in a separate **Authoring Editor** simulation rather than being edited directly in the CSDB view. The CSDB retains repository/workflow responsibility, while the editor view represents a dedicated XML authoring tool. Changes are stored only in browser localStorage; the bundled Bike XML is not modified.
